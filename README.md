# Prospect Analyzer — Matchbox Score Breakdown

An interactive, responsive 16:9 presentation deck breaking down the Prospect Analyzer audit for Matchbox.

## Live Deck

[Open the Matchbox presentation](https://loreeenzz.github.io/matchbox-score-breakdown/)

## Features

- Evidence lightbox for audit screenshots
- Score breakdown across Google Business Profile, website performance, and social presence
- Keyboard navigation with arrow keys, Space, Page Up, Page Down, Home, and End
- Fullscreen mode with `F`

## Local Use

Open `index.html` in a browser. The presentation uses `deck.js`, `styles.css`, and the `assets/` folder at the repository root.
